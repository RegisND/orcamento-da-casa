# Orçamento da Casa

App web de controle de gastos familiar, desenvolvido para o projeto de extensão
"Economia Sustentável" do curso de Análise e Desenvolvimento de Sistemas (Cruzeiro do Sul Virtual).

- Lançamento de entradas e gastos por categoria, mês a mês.
- Divisão da renda em essencial, livre e guardado, comparada à regra 50/30/20.
- Gastos por categoria e repetição das contas fixas do mês anterior.
- Dados salvos apenas no aparelho do usuário, sem login e sem servidor; funciona offline (PWA).

Ferramenta de organização pessoal; não é consultoria financeira.
